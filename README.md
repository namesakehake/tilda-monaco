# Tilda Monaco

Userscript для Tampermonkey: Monaco вместо Ace в HTML-редакторе Тильды, темы, форматирование и кнопки публикации.

## Состав

- `src/tilda-monaco.user.js` — полный исходник, который Tampermonkey читает с диска.
- `src/tilda-monaco.css` — оформление панели, кнопок, iframe и окна выбора темы.
- `tests/project-publish.test.cjs` — проверки сохранения и публикации через штатные функции Тильды.
- `tests/minify.test.cjs` — проверки отменяемого применения результата, ошибок, таймаута и изменений во время минификации.
- `tests/minify-css.integration.mjs` — проверка настоящего CSS-парсера, включая вложенность и экранирование внутри HTML; требует доступа к CDN.
- `.gitignore` — исключение служебных файлов macOS.

Сборка и установка npm-зависимостей не нужны.

## Подключение локального файла

Этот способ поддерживается Tampermonkey в Chrome и браузерах на Chromium, включая Helium. Локальный сервер и S3 не нужны.

1. Откройте сведения о расширении Tampermonkey в браузере и включите доступ к файлам по ссылкам `file://`.
2. В редакторе существующего скрипта Tampermonkey оставьте следующий заголовок. Если проект лежит в другой папке, исправьте абсолютные пути в `@require` и `@resource`.

```js
// ==UserScript==
// @name         Tilda — Monaco HTML + публикация
// @namespace    local.tilda.monaco
// @version      1.1.9
// @description  Monaco и публикация Тильды. JS и CSS подключаются из локальной Git-папки.
// @match        https://tilda.ru/page/*
// @match        https://tilda.cc/page/*
// @run-at       document-end
// @noframes
// @sandbox      raw
// @grant        unsafeWindow
// @grant        GM_registerMenuCommand
// @grant        GM_openInTab
// @grant        GM_getResourceText
// @resource     tmlStyles file:///Users/golygin/Downloads/tilda-monaco/src/tilda-monaco.css
// @require      file:///Users/golygin/Downloads/tilda-monaco/src/tilda-monaco.user.js
// ==/UserScript==

// Основной код выполняется из локального файла через @require.
```

3. Сохраните скрипт в Tampermonkey и перезагрузите страницу редактора Тильды.

Скрипт работает на `https://tilda.ru/page/*` и `https://tilda.cc/page/*`.

Способ подключения описан в [официальной инструкции Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q402).

CSS читается через `GM_getResourceText` и добавляется по одному разу на документ: на страницу Тильды и внутрь iframe Monaco. Размеры, зависящие от окна и состояния редактора, вычисляются в JS. Стили самой библиотеки Monaco загружаются из CDN.

## Возможности

- HTML-редактор шириной 80% окна, подсказки для HTML и встроенных CSS/JavaScript.
- Форматирование Prettier, отступ в четыре пробела, темы и стандартные сочетания клавиш Monaco.
- Команда «Минифицировать HTML / Minify HTML» в палитре F1 и контекстном меню редактора.
- Открытие опубликованной страницы, публикация текущей страницы и всего сайта через функции Тильды.

## Минификация

Откройте HTML-редактор, нажмите F1 и выберите «Минифицировать HTML / Minify HTML». Команда обрабатывает весь блок, включая встроенные CSS и JavaScript, и показывает уменьшение размера в байтах UTF-8. Результат отменяется одним Cmd/Ctrl+Z.

Минификатор загружается при первом запуске команды и работает в отдельном Worker. Код блока обрабатывается в браузере и не отправляется внешнему сервису.

Настройки сохраняют имена JavaScript, пути CSS и пробелы HTML-текста, значимость которых может зависеть от стилей страницы. Поэтому HTML не обязательно становится одной строкой. Для CSS используется CSSTree: он компактно записывает синтаксис, сохраняя порядок правил и современную вложенность. Нераспознанные фрагменты CSS сохраняются как исходный текст. Агрессивные преобразования кода отключены; обычные HTML-комментарии удаляются, а специальные комментарии библиотека сохраняет по своим правилам.

Если текст изменился во время обработки, результат не применяется. Ошибка или таймаут также не заменяют код; повторный запуск создаст новый Worker. При отсутствии уменьшения размера редактор остаётся без изменений. Сохранение и публикация выполняются штатными кнопками Тильды.

## Обновление

Правьте `src/tilda-monaco.user.js` или `src/tilda-monaco.css`, сохраняйте файл и перезагружайте Тильду. Tampermonkey подхватит изменения с диска; заново вставлять код, запускать сервер или повышать `@version` для этого не требуется. Уже открытый редактор обновится после перезагрузки страницы.

При переносе папки обновите пути в `@require` и `@resource`. Если меняете метаданные исходника, например `@match` или `@grant`, перенесите эти изменения и в заголовок установленного скрипта: метаданные подключаемого файла Tampermonkey не применяет. Номер `@version` в списке Tampermonkey также не синхронизируется с исходником автоматически.

Сам Monaco загружается из CDN: скрипт определяет последнюю стабильную версию при первом открытии HTML-редактора на странице. Редактор, его стили и workers используют одну и ту же версию.

Остальные зависимости закреплены на проверенных версиях. При обновлении Prettier его standalone-модуль и все плагины нужно переводить на одну версию одновременно. Браузерная сборка минификатора уже содержит свои зависимости.

| Библиотека | Версия |
| --- | --- |
| Monaco Editor | Последняя стабильная при открытии редактора |
| Prettier и плагины | 3.9.6 |
| HTML Minifier Terser | 7.2.0 |
| CSSTree, минификация CSS | 3.2.1 |
| Monaco Themes | 0.4.8 |
| VS Code CSS Language Service | 6.3.10 |
| process, браузерный модуль | 0.11.10 |

## Проверка перед коммитом

При установленном Node.js выполните из папки проекта:

```sh
node --check src/tilda-monaco.user.js
node --test tests/*.test.cjs
```

Тесты используют заглушки Тильды, Monaco и Worker, не обращаются к сети и не публикуют реальные страницы.

После изменения CSS-минификации дополнительно проверьте библиотеку из CDN:

```sh
node --test tests/minify-css.integration.mjs
```
