# Tilda Monaco

Удобный редактор HTML-кода внутри Тильды: подсказки, форматирование, темы, минификация и быстрые кнопки публикации. Дополнительно можно копировать ID и CSS-класс блока прямо из его панели.

Это неофициальный userscript — небольшой скрипт, который расширение **Tampermonkey** запускает в вашем браузере. Он улучшает интерфейс редактора; посетителям опубликованного сайта устанавливать ничего не нужно.

[Установка](#установка) · [Как пользоваться](#как-пользоваться) · [Обновление](#обновление) · [Решение проблем](#решение-проблем)

## Что умеет

- Заменяет Ace на Monaco в HTML-поле блока: подсказки HTML, а также CSS внутри `<style>` и JavaScript внутри `<script>`.
- Расширяет окно HTML-редактора до 80% экрана; на узком экране — до полной ширины.
- Форматирует документ через Prettier, использует четыре пробела для отступа.
- Добавляет минификацию HTML со встроенными CSS и JavaScript, с отменой результата.
- Поддерживает светлые, тёмные, контрастные темы, системную тему и дополнительный каталог.
- Включает сворачивание кода, мини-карту, перенос длинных строк, подсветку парных скобок, цветов и пробелов в конце строк.
- Позволяет быстро сохранить и опубликовать страницу, открыть опубликованную страницу или опубликовать весь текущий сайт.
- Показывает кнопки копирования `#rec…` и `uc-…` справа сверху у блока, рядом со стрелками перемещения.

## Что понадобится

Настольный **Chrome или браузер на Chromium**, например Helium или Edge, расширение Tampermonkey и доступ к редактированию страницы Тильды. Для проверки Monaco нужен блок с HTML-кодом, например **T123 → «Контент»**.

Инструкция использует локальные файлы. Этот способ подключения поддерживается Tampermonkey в Chrome и его производных; для Firefox и Safari он не подходит. [Справка Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q204).

Сервер, S3, Node.js, терминал, Git и установка npm-пакетов для обычного использования не нужны. Интернет нужен для Тильды и загрузки библиотек редактора.

## Установка

### 1. Установите Tampermonkey

Откройте [официальный сайт Tampermonkey](https://www.tampermonkey.net/), выберите свой браузер и перейдите по ссылке в его магазин расширений. Установите расширение; при желании закрепите его значок на панели браузера.

Текущий код и инструкция рассчитаны на Tampermonkey.

### 2. Разрешите запуск скриптов и чтение локальных файлов

Откройте управление расширениями: `chrome://extensions` в Chrome/Helium или `edge://extensions` в Edge. Найдите **Tampermonkey → «Подробнее»**.

- Включите **«Разрешить пользовательские скрипты» / Allow User Scripts**, если такой переключатель есть. Если его нет, используйте **«Режим разработчика» / Developer mode** на странице расширений. Это два предусмотренных Tampermonkey способа разрешить запуск; одновременно включать оба не требуется. [Официальная инструкция](https://www.tampermonkey.net/faq.php?q=Q209).
- Включите **«Разрешить доступ к URL файлов» / Allow access to file URLs** — чтобы расширение могло прочитать скачанные JS и CSS. [Инструкция с пояснениями](https://www.tampermonkey.net/faq.php?q=Q204).
- Убедитесь, что доступ расширения к сайтам разрешает работу на `tilda.ru` и/или `tilda.cc`, которыми вы пользуетесь.

Остальные настройки Tampermonkey для этой установки можно оставить стандартными. Режим выполнения и необходимые API уже указаны в заголовке ниже.

### 3. Скачайте и распакуйте проект

На странице [репозитория](https://github.com/namesakehake/tilda-monaco) нажмите **Code → Download ZIP**. Распакуйте архив, переименуйте полученную папку в `tilda-monaco` и положите её в постоянное место, например «Документы».

Внутри должны быть оба файла:

```text
tilda-monaco/
└── src/
    ├── tilda-monaco.user.js
    └── tilda-monaco.css
```

Архив ZIP после распаковки больше не нужен. Саму папку с файлами сохраните: Tampermonkey будет читать её при открытии Тильды.

### 4. Создайте скрипт в Tampermonkey

Нажмите значок Tampermonkey → **«Создать новый скрипт…»**. Если пункта нет, откройте его **«Панель управления»** и нажмите вкладку с плюсом. Удалите шаблон из редактора и вставьте весь заголовок ниже.

**Замените `FULL/PATH/TO` в двух последних строках на свой путь к папке. Готовые примеры для Windows и macOS — сразу под заголовком.**

```js
// ==UserScript==
// @name         Tilda — Monaco HTML + публикация
// @namespace    local.tilda.monaco
// @version      1.1.10
// @description  Monaco, публикация и копирование ID/классов блоков Тильды. JS и CSS из локальной папки.
// @match        https://tilda.ru/page/*
// @match        https://tilda.cc/page/*
// @run-at       document-end
// @noframes
// @sandbox      raw
// @grant        unsafeWindow
// @grant        GM_registerMenuCommand
// @grant        GM_openInTab
// @grant        GM_getResourceText
// @resource     tmlStyles file:///FULL/PATH/TO/tilda-monaco/src/tilda-monaco.css
// @require      file:///FULL/PATH/TO/tilda-monaco/src/tilda-monaco.user.js
// ==/UserScript==

// Основной код выполняется из локального файла через @require.
```

**Windows:** если папка находится в `C:\Users\YOUR_NAME\Documents\tilda-monaco`, замените две строки на:

```js
// @resource     tmlStyles file:///C:/Users/YOUR_NAME/Documents/tilda-monaco/src/tilda-monaco.css
// @require      file:///C:/Users/YOUR_NAME/Documents/tilda-monaco/src/tilda-monaco.user.js
```

**macOS:** если папка находится в `/Users/YOUR_NAME/Documents/tilda-monaco`, используйте:

```js
// @resource     tmlStyles file:///Users/YOUR_NAME/Documents/tilda-monaco/src/tilda-monaco.css
// @require      file:///Users/YOUR_NAME/Documents/tilda-monaco/src/tilda-monaco.user.js
```

`YOUR_NAME` — имя вашей папки пользователя, а не текст, который нужно оставить как есть. Если «Документы» находятся в OneDrive или папка проекта называется иначе, укажите её фактический путь.

В адресах нужны прямые слеши `/`, начало `file:///` и полный путь к файлу. Не используйте `~`, переменные окружения или кавычки вокруг адреса. Пробелы в URL записываются как `%20`.

Чтобы получить адрес без ручного преобразования, откройте именно файл **`tilda-monaco.css`** в браузере через «Открыть файл» (`Ctrl+O` / `Cmd+O`) и скопируйте адрес из адресной строки. Для второй строки измените только имя файла на `tilda-monaco.user.js`.

Внутри Tampermonkey остаётся этот короткий заголовок. Весь код из `src/tilda-monaco.user.js` дополнительно вставлять туда не нужно. Строка `@require` подключает JS, а именованный ресурс `tmlStyles` — CSS; имя `tmlStyles` оставьте без изменений. [Как работает подключение локального исходника](https://www.tampermonkey.net/faq.php?q=Q402), [описание `@require` и `@resource`](https://www.tampermonkey.net/documentation.php?q=externals).

### 5. Сохраните и проверьте

1. Сохраните скрипт в редакторе Tampermonkey через **«Файл → Сохранить»** или `Ctrl+S` / `Cmd+S`. Убедитесь, что сам скрипт включён.
2. Отключите предыдущую копию этого же скрипта, если она установлена через другой userscript или менеджер, чтобы две версии не работали одновременно.
3. Откройте страницу **в режиме редактирования Тильды** и перезагрузите вкладку.
4. В верхней панели должны появиться дополнительные кнопки публикации и открытия страницы. При наведении на блок — кнопка `#rec…` справа сверху.
5. Откройте **T123 → «Контент» → поле HTML-кода**. При первом открытии дождитесь загрузки Monaco. Нажмите правой кнопкой в коде: в меню должны быть «Минифицировать HTML / Minify HTML» и «Тема редактора / Color Theme».

Скрипт запускается только на `https://tilda.ru/page/*` и `https://tilda.cc/page/*`. На опубликованном сайте и внутри отдельного редактора Zero Block (`/zero/`) эти дополнения не запускаются. Обычные текстовые поля Тильды также не заменяются на Monaco.

## Как пользоваться

### Редактирование и сохранение

Открывайте HTML-поле блока как обычно. Monaco отображает код, а скрипт синхронизирует изменения со штатным Ace и полем формы, из которых Тильда сохраняет блок.

- `Tab` делает отступ в четыре пробела; `Shift+Tab` уменьшает отступ. Длинные строки переносятся визуально.
- Автоподсказки появляются при вводе; учитываются HTML и встроенные CSS/JavaScript. Это редактор отдельного HTML-блока, без доступа к файлам и зависимостям полноценного проекта. Emmet не подключён.
- Сохраняйте штатными кнопками Тильды. **`Ctrl+S` / `Cmd+S` внутри Monaco** вызывает штатное сохранение блока без публикации.
- Одного ввода текста недостаточно для сохранения на сервере. Перед закрытием или перезагрузкой вкладки сохраните блок.

**F1** открывает палитру команд Monaco: начните вводить имя нужного действия. Если клавиша занята системой, используйте `Fn+F1` или контекстное меню редактора. Для сочетаний клавиш сначала кликните в код, чтобы фокус был внутри Monaco.

### Форматирование и минификация

| Задача | Как запустить | Результат |
| --- | --- | --- |
| Привести весь код к читаемому виду | F1 → **Format Document** или соответствующий пункт контекстного меню | Prettier форматирует HTML и встроенные CSS/JavaScript; отступ — четыре пробела |
| Уменьшить размер кода | F1 или контекстное меню → **Минифицировать HTML / Minify HTML** | Обрабатывается весь блок; уведомление показывает уменьшение в процентах и байтах |
| Отменить изменение | `Ctrl+Z` / `Cmd+Z` внутри редактора | Возвращается предыдущий текст; результат минификации отменяется одним действием |

Форматирование при вставке и наборе включено там, где его поддерживает языковой сервис. Для предсказуемого форматирования всего блока используйте **Format Document**.

Форматировщик и минификатор загружаются при первом обращении и работают в отдельных workers браузера. Текст блока не отправляется внешнему сервису форматирования. Если код изменился во время обработки, устаревший результат не применяется; при ошибке или таймауте исходный текст остаётся в редакторе.

Минификация сохраняет имена JavaScript, порядок CSS и значимые HTML-пробелы. Нераспознанные фрагменты CSS остаются исходным текстом. Обычные HTML-комментарии удаляются, специальные комментарии библиотека сохраняет по своим правилам. HTML не обязательно превращается в одну строку. Если уменьшения размера нет, код не заменяется. Сохранение и публикация остаются отдельными действиями.

### Темы

Откройте **F1 → «Тема редактора / Color Theme»** или одноимённый пункт контекстного меню. Можно также нажать **Tampermonkey → «Тема редактора…»**, когда HTML-редактор уже открыт.

В окне есть поиск, встроенные светлая, тёмная, контрастные и системная темы, а также дополнительный каталог. Стрелки `↑` / `↓` показывают предпросмотр, `Enter` подтверждает выбор, `Esc` отменяет. Выбранная тема сохраняется в браузере для этого домена Тильды; очистка данных сайта сбросит выбор.

### Публикация и открытие страницы

Наведите курсор на иконку в верхней панели — её подсказка показывает действие. Дополнительные иконки идут слева направо: **весь сайт → текущая страница → открыть страницу**.

| Действие | Как выполнить |
| --- | --- |
| Сохранить открытый блок и опубликовать текущую страницу | Иконка **«Быстрая публикация»** или `Ctrl+Shift+S` / `Cmd+Shift+S` |
| После публикации сразу открыть страницу | `Alt` / `Option` + клик по быстрой публикации; либо добавить `Alt` / `Option` к сочетанию выше |
| Сохранить и опубликовать из формы блока | `Shift` + клик по штатной кнопке сохранения |
| Сохранить, опубликовать и открыть из формы блока | `Alt` / `Option` + клик по штатной кнопке сохранения |
| Открыть уже опубликованную страницу | Иконка **«Открыть опубликованную страницу»** |
| Открыть страницу с новым параметром URL | `Shift` + клик по иконке открытия |
| Опубликовать весь текущий сайт | Отдельная иконка **«Опубликовать весь сайт»** в верхней панели или рядом с кнопками сохранения в редакторе блока |

Кнопки публикации запускают действие сразу. «Весь сайт» означает страницы **текущего проекта**, кроме страниц в архивных папках. Скрипт использует текущую авторизацию, штатное сохранение, данные проекта и механизм запросов публикации Тильды; учитывает права на публикацию. Список страниц не нужно прописывать вручную.

Во время публикации сайта показывается прогресс. Если Тильда вернула ошибку, процесс останавливается с сообщением; уже опубликованные страницы не откатываются. При сообщении об открытом виджете сначала завершите его редактирование.

При открытии сразу после публикации и при `Shift` + клике к адресу добавляется `tml_preview=…`. Это новый URL для запроса страницы, а не очистка всего кеша браузера или кеша отдельных картинок, CSS и JS.

### Копирование ID и класса блока

Наведите курсор на блок. В верхней правой группе, рядом со стрелками перемещения, появятся:

- **`#rec…`** — копирует ID в том же формате, что штатное меню Тильды; для блока-алиаса используется ID исходного блока.
- **`uc-…`** — копирует пользовательский CSS-класс без точки. Кнопка видна, только если класс задан через **CSS Class Name** в меню блока; после изменения класса обновляется автоматически.

Нажатие вызывает штатное копирование и уведомление Тильды. Для CSS-селектора класса перед скопированным `uc-…` добавьте точку: `.uc-example`.

## Обновление

**Monaco и этот userscript обновляются по-разному.**

- **Monaco:** при первом открытии HTML-редактора после загрузки страницы скрипт узнаёт последнюю стабильную версию в npm. Редактор, его стили и workers используют одну версию. Уже открытая вкладка не переключается на новый релиз посреди работы.
- **Код этого проекта:** скачайте свежий архив из репозитория и замените **оба файла из `src`** в своей постоянной папке. Затем сохраните открытый блок и перезагрузите Тильду. Новые коммиты GitHub сами на диск не скачиваются.
- **Ваши локальные правки:** сохраните JS/CSS на диске и перезагрузите Тильду. Заново вставлять основной код в Tampermonkey или повышать `@version` для этого не нужно.
- **Остальные библиотеки:** закреплены на конкретных версиях в исходнике и обновляются вместе с кодом проекта. Prettier намеренно не использует `latest`.

Если перенесли или переименовали папку, исправьте оба пути в установленном скрипте Tampermonkey. Если новая версия меняет `@grant`, `@match` или другие настройки заголовка, перенесите их в Tampermonkey тоже: метаданные подключаемого через `@require` файла не заменяют настройки установленного скрипта.

Номер версии в списке Tampermonkey не синхронизируется с исходником автоматически. Настройка **«Внешние ресурсы → Интервал обновления»** не управляет выбором версии Monaco: её скрипт определяет отдельным запросом.

## Решение проблем

| Что происходит | Что проверить |
| --- | --- |
| Нет ни дополнительных иконок, ни Monaco | Вы в редакторе `/page/`, Tampermonkey и скрипт включены, запуск пользовательских скриптов разрешён. После установки перезагрузите вкладку |
| Иконок нет, в Tampermonkey ошибка чтения файла | Доступ к `file://`, обе строки путей, распаковку ZIP, имя папки и расширения файлов. Файл не должен называться `.js.txt` или `.css.txt` |
| После скачивания новой версии ничего не изменилось | Замените файлы именно по пути из установленного заголовка. Соседняя папка `tilda-monaco-main` не подхватится вместо прежней |
| Иконки есть, но в HTML-поле остался Ace | Monaco не загрузился или поле не поддерживается. Проверьте T123 → «Контент» и доступность CDN; при сбое скрипт возвращает штатный редактор |
| Редактор или кнопки без оформления | Проверьте файл `tilda-monaco.css`, строку `@resource tmlStyles …` и разрешение чтения локальных файлов |
| Темы, подсказки, форматирование или минификация долго загружаются | Библиотеки загружаются через сеть; проверьте доступность `registry.npmjs.org`, `esm.sh` и `cdn.jsdelivr.net` и сообщения о блокировке этих запросов |
| Не работает сочетание клавиш | Кликните в код. Для команд редактора используйте F1 или контекстное меню; системные сочетания могут перехватываться ОС или расширениями |
| Форматирование показывает ошибку | Исправьте указанное место в HTML/CSS/JavaScript и повторите Format Document; сообщение появляется в редакторе |
| Публикация остановилась | Прочитайте сообщение Тильды: проверьте авторизацию, права на публикацию и завершите редактирование открытого виджета. Можно проверить действие штатной кнопкой Тильды |
| Нет кнопки `uc-…` | У этого блока не задан пользовательский CSS Class Name; одной кнопки ID в таком случае достаточно |
| Дублируются кнопки или поведение конфликтует | Оставьте включённой одну копию этого userscript. Проверьте другие расширения, которые меняют редактор или панель Тильды |

Если доступ расширения ограничен отдельными сайтами и локальные файлы всё равно не читаются, [Tampermonkey отмечает](https://www.tampermonkey.net/faq.php?q=Q204), что для `file://` иногда требуется режим доступа **«На всех сайтах»**. Сам userscript ограничен адресами редактора Тильды через `@match`.

После обновления интерфейса Тильды внутренние функции или разметка могут измениться: тогда потребуется адаптация скрипта. Если проблема сохраняется, откройте [Issue](https://github.com/namesakehake/tilda-monaco/issues) и укажите браузер и его версию, версию Tampermonkey и исходника, тип блока, шаги повторения и текст ошибки. Пароли, cookies и токены прикладывать не нужно.

## Как отключить

Сохраните открытый блок, выключите userscript в меню Tampermonkey и перезагрузите Тильду. Вернутся стандартный редактор и панель. Уже сохранённый код блока и опубликованные изменения останутся в Тильде.

## Для разработчиков

### Файлы и устройство

- `src/tilda-monaco.user.js` — логика редактора, синхронизация со штатным Ace, темы, минификация, публикация и кнопки блоков.
- `src/tilda-monaco.css` — оформление панели, кнопок, iframe и окна выбора темы.
- `tests/project-publish.test.cjs` — проверки сохранения и публикации через функции Тильды.
- `tests/minify.test.cjs` — проверки отмены, ошибок, таймаута и изменений во время минификации.
- `tests/minify-css.integration.mjs` — проверка реального CSS-парсера, включая вложенность и экранирование внутри HTML; требует доступа к CDN.

Monaco работает в отдельном iframe, чтобы его сочетания клавиш не перехватывались редактором страницы. CSS читается через `GM_getResourceText` и добавляется один раз на документ. Встроенные CSS и JavaScript получают языковые подсказки через отдельные модели; сохранение продолжает идти через форму Тильды.

`unsafeWindow` и `@sandbox raw` нужны для взаимодействия с функциями страницы, `GM_getResourceText` — для CSS, `GM_openInTab` — для открытия вкладки после асинхронной публикации, `GM_registerMenuCommand` — для команд в меню расширения. [Режим выполнения](https://www.tampermonkey.net/documentation.php?q=sandbox), [разрешения API](https://www.tampermonkey.net/documentation.php?q=grant).

### Зависимости

| Библиотека | Версия в исходнике |
| --- | --- |
| Monaco Editor | Последняя стабильная при первом открытии редактора |
| Prettier и плагины | 3.9.6 |

При обновлении Prettier его standalone-модуль и все плагины нужно переводить на одну версию одновременно. Браузерная сборка HTML-минификатора содержит свои зависимости; CSS обрабатывается отдельно через CSSTree.

### Проверка изменений

Эти команды нужны разработчику, а не пользователю при установке. Из папки проекта, при установленном Node.js:

```sh
node --check src/tilda-monaco.user.js
node --test tests/*.test.cjs
```

Тесты используют заглушки Тильды, Monaco и Worker, не обращаются к сети и не публикуют реальные страницы. Изменения интерфейса дополнительно проверяются в открытом редакторе Тильды.

После изменения CSS-минификации проверьте библиотеку из CDN:

```sh
node --test tests/minify-css.integration.mjs
```
