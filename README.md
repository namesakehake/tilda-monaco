# Tilda Monaco

Полный userscript для Tampermonkey: Monaco вместо Ace в HTML-редакторе Тильды, темы, форматирование и кнопки публикации.

## Состав

- `src/tilda-monaco.user.js` — полный исходник, который Tampermonkey читает с диска.
- `tests/project-publish.test.cjs` — проверки сохранения и публикации через штатные функции Тильды.
- `.gitignore` — исключение служебных файлов macOS.

Сборка и установка npm-зависимостей не нужны.

## Подключение локального файла

Этот способ поддерживается Tampermonkey в Chrome и браузерах на Chromium, включая Helium. Локальный сервер и S3 не нужны.

1. Откройте сведения о расширении Tampermonkey в браузере и включите доступ к файлам по ссылкам `file://`.
2. В редакторе существующего скрипта Tampermonkey оставьте следующий заголовок. Если проект лежит в другой папке, исправьте абсолютный путь в `@require`.

```js
// ==UserScript==
// @name         Tilda — Monaco HTML + публикация
// @namespace    local.tilda.monaco
// @version      1.1.7
// @description  Monaco и публикация Тильды. Исходник подключается из локальной Git-папки.
// @match        https://tilda.ru/page/*
// @match        https://tilda.cc/page/*
// @run-at       document-end
// @noframes
// @sandbox      raw
// @grant        unsafeWindow
// @grant        GM_registerMenuCommand
// @grant        GM_openInTab
// @require      file:///Users/golygin/Downloads/tilda-monaco/src/tilda-monaco.user.js
// ==/UserScript==

// Основной код выполняется из локального файла через @require.
```

3. Сохраните скрипт в Tampermonkey и перезагрузите страницу редактора Тильды.

Скрипт работает на `https://tilda.ru/page/*` и `https://tilda.cc/page/*`.

Способ подключения описан в [официальной инструкции Tampermonkey](https://www.tampermonkey.net/faq.php?q=Q402).

## Возможности

- HTML-редактор шириной 80% окна, подсказки для HTML и встроенных CSS/JavaScript.
- Форматирование Prettier, отступ в четыре пробела, темы и стандартные сочетания клавиш Monaco.
- Открытие опубликованной страницы, публикация текущей страницы и всего сайта через функции Тильды.

## Обновление

Правьте `src/tilda-monaco.user.js`, сохраняйте файл и перезагружайте Тильду. Tampermonkey подхватит изменения с диска; заново вставлять код, запускать сервер или повышать `@version` для этого не требуется. Уже открытый редактор обновится после перезагрузки страницы.

При переносе папки обновите путь в `@require`. Если меняете метаданные исходника, например `@match` или `@grant`, перенесите эти изменения и в заголовок установленного скрипта: метаданные подключаемого файла Tampermonkey не применяет.

Сам Monaco загружается из CDN: скрипт определяет последнюю стабильную версию при первом открытии HTML-редактора на странице. Редактор, его стили и workers используют одну и ту же версию.

## Проверка перед коммитом

При установленном Node.js выполните из папки проекта:

```sh
node --check src/tilda-monaco.user.js
node --test tests/project-publish.test.cjs
```

Тесты используют заглушки функций Тильды и не публикуют реальные страницы.
