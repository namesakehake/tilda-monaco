# Скриншоты Tilda Monaco

Реальные скриншоты редактора Тильды и настроек Tampermonkey, подготовленные 22 сентября 2026 года в Helium на macOS. Изображения сохранены в PNG без потерь, без рамки браузера и списка вкладок. Скриншот Tampermonkey предоставлен пользователем и обрезан до раздела обновления пользовательских скриптов. Код в редакторе — демонстрационный пример; в Тильде он не сохранялся.

Файлы находятся в [`docs/images`](images). Их можно использовать в постах, обзорах и инструкциях. Для публикации откройте оригинал нужного изображения, чтобы не использовать уменьшенную картинку из предпросмотра README.

## Автоматическое обновление в Tampermonkey

Подпись для поста: «Устанавливаешь скрипт один раз по ссылке. В Tampermonkey выбираешь ежедневную проверку и включаешь автоматическую установку — новые версии приходят с GitHub».

![Ежедневная проверка и автоматическая установка обновлений в Tampermonkey 5.5.0](images/tampermonkey-auto-updates.png)

[Оригинал — 684 × 116](images/tampermonkey-auto-updates.png)

Нужный раздел — **«Обновление пользовательских скриптов»**. Пункт **«Никогда»** в разделе **«Внешние ресурсы»** ниже относится к зависимостям и не отключает обновления самого скрипта.
