# Решение проблем

[← Вернуться к README](../README.md) · [Подробное руководство](usage.md)

## Ссылка открыла исходный код

1. Скопируйте [адрес установочного файла](https://raw.githubusercontent.com/namesakehake/tilda-monaco/main/dist/tilda-monaco.user.js).
2. Откройте **Tampermonkey → «Панель управления» → «Утилиты»**.
3. Вставьте адрес в поле **«Установить с URL»** и запустите установку.
4. В открывшемся окне проверьте название **«Tilda — Monaco HTML + публикация»** и нажмите **«Установить»**. Для уже установленной копии кнопка может называться **«Перезаписать»**.

В поле нужен адрес файла, а не его исходный код. Названия пунктов могут отличаться в зависимости от языка расширения.

## Скрипт не запускается

Проверьте, что Tampermonkey и скрипт включены. Затем откройте `chrome://extensions` в Chrome/Helium или `edge://extensions` в Edge → **Tampermonkey → «Подробнее»**:

- Включите **«Разрешить пользовательские скрипты» / Allow User Scripts**. Если такого переключателя нет, включите **«Режим разработчика» / Developer mode** на странице расширений. [Официальная инструкция](https://www.tampermonkey.net/faq.php?q=Q209).
- Доступ расширения к сайтам должен разрешать работу на `tilda.ru` и/или `tilda.cc`, которыми вы пользуетесь.

Перезагрузите редактор страницы Тильды и откройте **T123 → «Контент»**. При первом открытии дождитесь загрузки Monaco. [Где работает скрипт](usage.md#где-работает-скрипт).

## Обновления не приходят

В **Tampermonkey → «Панель управления» → «Настройки» → «Обновление пользовательских скриптов»** выберите интервал проверки, отличный от «Никогда», и включите **«Автоматическая установка»**.

Раздел **«Внешние ресурсы»** относится к зависимостям. Значение «Никогда» в нём не отключает обновления самого Tilda Monaco.

Для немедленного обновления запустите проверку вручную в панели Tampermonkey или снова откройте [ссылку установки](https://raw.githubusercontent.com/namesakehake/tilda-monaco/main/dist/tilda-monaco.user.js). После установки новой версии сохраните открытый блок и перезагрузите Тильду.

## Переход с локальной версии

Установите скрипт по [публичной ссылке](https://raw.githubusercontent.com/namesakehake/tilda-monaco/main/dist/tilda-monaco.user.js). Если Tampermonkey предложит заменить прежнюю копию, подтвердите замену. Оставьте включённой только одну копию.

Локальное подключение продолжает читать файлы с компьютера и не получает обновления с GitHub. Для него есть [инструкция разработчика](development.md#локальное-подключение).

## Другие ситуации

| Что происходит | Что проверить |
| --- | --- |
| Ошибка чтения локального файла | Вы используете режим разработки. Проверьте пути и разрешения по [инструкции](development.md) или установите [публичную версию](https://raw.githubusercontent.com/namesakehake/tilda-monaco/main/dist/tilda-monaco.user.js) |
| Иконки есть, но в HTML-поле остался Ace | Monaco не загрузился или поле не поддерживается. Проверьте T123 → «Контент» и доступность CDN; при сбое скрипт возвращает штатный редактор |
| Редактор или кнопки без оформления | Обновите установленный скрипт и перезагрузите Тильду: CSS входит в установочный файл. Для локального подключения проверьте `@resource` по инструкции разработчика |
| Темы, подсказки, форматирование или минификация долго загружаются | Библиотеки загружаются через сеть; проверьте доступность `registry.npmjs.org`, `esm.sh` и `cdn.jsdelivr.net` и сообщения о блокировке этих запросов |
| Не работает сочетание клавиш | Кликните в код. Для команд редактора используйте F1 или контекстное меню; системные сочетания могут перехватываться ОС или расширениями |
| Форматирование показывает ошибку | Исправьте указанное место в HTML/CSS/JavaScript и повторите Format Document; сообщение появляется в редакторе |
| Публикация остановилась | Прочитайте сообщение Тильды: проверьте авторизацию, права на публикацию и завершите редактирование открытого виджета. Можно проверить действие штатной кнопкой Тильды |
| Нет кнопки `uc-…` | У этого блока не задан пользовательский CSS Class Name; одной кнопки ID в таком случае достаточно |
| Дублируются кнопки или поведение конфликтует | Оставьте включённой одну копию этого userscript. Проверьте другие расширения, которые меняют редактор или панель Тильды |

## Сообщить об ошибке

После обновления интерфейса Тильды внутренние функции или разметка могут измениться: тогда потребуется адаптация скрипта. Если проблема сохраняется, откройте [Issue](https://github.com/namesakehake/tilda-monaco/issues) и укажите браузер и его версию, версию Tampermonkey и исходника, тип блока, шаги повторения и текст ошибки. Пароли, cookies и токены прикладывать не нужно.
